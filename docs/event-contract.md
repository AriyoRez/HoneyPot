# Event Contract (v0.2)

> **Status: approved v0.2.** This is the canonical contract between the OpenCanary
> log and everything downstream. The reader (`app/reader/`) produces normalized
> events in this shape; rules (`app/rules/`), dashboards (`app/dashboards/`), and
> test fixtures (`tests/fixtures/`) consume them. Change this doc first, then the
> code — not the other way around.

The pipeline is `OpenCanary log → reader (normalize + sanitize) → normalized event
→ rules / dashboards`. There is **no** CrowdStrike / CPS target; we own both ends.

## Sanitization policy (non-negotiable)

- **Never store plaintext passwords.** The reader records `password_present`
  (bool) and `password_sha256` (one-way hash) only. The hash lets analysts spot
  reused credentials across attempts without ever persisting the secret.
- **`src_ip`:** kept in full in the normalized log (traffic is synthetic, lab-only).
  Mask the last octet only when exporting to `evidence/` (screenshots/logs).
- **`sensor_node`:** always a non-identifying label (e.g. `decoy-01`). Never a real
  hostname. The reader maps OpenCanary's `node_id` to such a label.
- `logdata` values other than those mapped below are **dropped**; only their keys
  are retained in `raw_logdata_keys` as an audit trail.

## Normalized event schema

| Field | Type | Source (OpenCanary) | Notes |
|---|---|---|---|
| `event_id` | string (uuid) | generated by reader | Stable ID for dedup / correlation. |
| `timestamp` | ISO-8601 UTC | `utc_time` | Normalized to UTC; `local_time` dropped. |
| `sensor_node` | string | `node_id` | Mapped to a non-identifying label. |
| `service` | enum `ssh\|http\|mysql` | derived from `logtype` (+ `dst_port`) | See derivation table. |
| `event_category` | enum `connection\|request\|auth_attempt` | derived from `logtype` | Analyst-facing event kind. Room for `probe` later. |
| `logtype_raw` | int | `logtype` | Raw code kept for traceability. |
| `src_ip` | string | `src_host` | Attacker IP (synthetic). Mask last octet in `evidence/`. |
| `src_port` | int | `src_port` | |
| `dst_ip` | string \| null | `dst_host` | The **decoy's own** listening IP. Lets the GUI tell decoys/hosts apart in a fleet. Mask last octet in `evidence/`. |
| `dst_port` | int | `dst_port` | Which decoy service was hit (e.g. 22/80/3306). |
| `username` | string \| null | `logdata.USERNAME` | Present on auth attempts. |
| `password_present` | bool | `logdata.PASSWORD` exists | Never store the value. |
| `password_sha256` | string \| null | SHA-256 of `logdata.PASSWORD` | One-way; null when no password. |
| `http_path` | string \| null | `logdata.PATH` | HTTP only. |
| `user_agent` | string \| null | `logdata.USERAGENT` | HTTP only. |
| `raw_logdata_keys` | string[] | keys of `logdata` | Audit trail of what was present; no values. |

## logtype → service / category derivation

| `logtype` | OpenCanary meaning | `service` | `event_category` |
|---|---|---|---|
| 4000 | SSH new connection | ssh | `connection` |
| 4001 | SSH remote version sent | ssh | `connection` |
| 4002 | SSH login attempt | ssh | `auth_attempt` |
| 3000 | HTTP GET | http | `request` |
| 3001 | HTTP POST login attempt | http | `auth_attempt` |
| 3002 | HTTP unimplemented method | http | `request` |
| 3003 | HTTP redirect | http | `request` |
| 8001 | MySQL login attempt | mysql | `auth_attempt` |
| 9003 | MySQL connection made | mysql | `connection` |

A `logtype` not in this table is **unmapped**: the reader should emit the event
with `service=null`/`event_category=null` (or route it to a dead-letter path) and
never silently drop it — surfacing unmapped types is part of pipeline health.

## How this serves the four detection use cases

| Use case | Satisfied by |
|---|---|
| Unexpected interaction | Any normalized event (the services have no legitimate users). |
| Authentication attempts | `event_category = auth_attempt` (+ `username`, `password_present`). |
| Multi-service probing | One `src_ip` seen across ≥2 distinct `service` values. |
| Pipeline health | `sensor_node` + `timestamp` freshness + event counts + unmapped-logtype rate. |
